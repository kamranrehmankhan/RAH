# Ethereal Solstice

Static HTML pages generated from the provided Stitch export.

## Pages

- `index.html` - home page
- `our-story.html` - brand story/editorial page
- `product.html` - product detail page
- `checkout.html` - secure checkout page
- `orders.html` - order history page

## Run locally

Open any page directly in the browser, or from this folder run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
